One sentence, at most 200 characters, in the voice of an alien tourist
giving planet Earth a one-star review while still slipping in a real
compliment about the food. `main.py` writes it to `/output/entry.txt`.

Entry for the [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7) bounty on [make.fun](https://make.fun).

Referral code: `4g7knchf`

## Run

```sh
python3 main.py                  # write the line to /output/entry.txt
python3 main.py --dest out.txt   # write it somewhere else instead
python3 main.py --self-test      # check the gate, print the hash, exit
```
